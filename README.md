# Cotizador Premedic

Cotizador web estático en HTML, CSS y JavaScript puro.

## Estado
Proyecto listo para publicación.

## Funciones incluidas
- Cotización Directo / Desregulado.
- AMBA / Interior.
- Composición individual, titular + hijo/s, pareja y pareja + hijo/s.
- Edad tarifaria automática: en pareja se toma la edad del mayor.
- Límite comercial de 59 años y 11 meses.
- Plan C-100 sólo en AMBA.
- Adicionales según composición y edad.
- Desregulado: aporte computable = (aporte del recibo ÷ 3) × 7,65.
- El aporte computable se descuenta del valor del plan.
- Si el aporte cubre o supera el plan, el total a abonar se muestra en $0.
- Selección de plan.
- Vista previa formal.
- Guardado como PDF mediante el diálogo de impresión del navegador.
- Cotización válida por 72 hs hábiles desde su emisión.
- ID automático de cotización.
- Datos opcionales del asesor.

## Uso local
Abrir `index.html` con Chrome, Edge o Firefox.

No requiere instalar paquetes ni ejecutar servidor.

## Portal comercial
La portada de acceso muestra únicamente la información necesaria y permite ingresar al Cotizador Premedic sin mezclar otras marcas.
